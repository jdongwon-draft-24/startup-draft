# 사업자등록 정보 입력

### 무엇을 하는 서비스인가

업종과 사업자등록일을 넣으면 그 업종에 맞는 세무·행정 항목 목록을 매번 찾아보지 않고 바로 보여 주는 서비스입니다.

- 업종과 사업자등록일을 넣고 "조회"를 누르면 그 업종에 맞는 세무·행정 항목 목록이 뜹니다.
- 항목마다 사업자등록일을 기준으로 계산한 마감이 함께 보입니다.
- 항목을 하나씩 완료 체크하면 아직 안 한 항목만 남아서 한눈에 보입니다.
- 항목 자료에 없는 업종을 넣으면 AI가 항목 자료에 있는 업종 가운데 가장 비슷한 업종을 찾아 "이 업종으로 볼까요?" 하고 물어봅니다.
  - AI(인공지능) — 사람 대신 글을 읽고 답을 골라 주는 컴퓨터 프로그램.
  - AI는 항목 자료에 이미 있는 업종 가운데서만 고르고, 세무·행정 항목을 새로 만들지 않습니다.

항목 자료는 [data/sample-tax-items.csv](data/sample-tax-items.csv) 에 있는 샘플 자료입니다. 지금은 IT 서비스 개발업, 온라인 쇼핑몰업, 음식점업 세 업종이 들어 있습니다.

### 누구를 위한 것인가

사업자등록한 지 1개월 된 IT 서비스 개발업 1인 창업자를 위한 서비스입니다.

- 사업 경험이 없어서 어떤 세무·행정 절차를 해야 하는지 자체를 모르는 사람
- 지금은 주위 창업한 선배들에게 물어보거나 세무사 등에게 문의하는 사람

이 서비스로 선배나 세무사에게 묻지 않아도 무엇을 해야 하는지 스스로 알 수 있습니다.

### 어떻게 쓰나

1. 첫 화면에서 **"시작하기"** 를 누릅니다.
2. 왼쪽 사이드바에서 **업종**을 고릅니다. 목록에 없는 업종은 직접 쳐서 넣습니다.
   - 사이드바 — 화면 왼쪽에 세로로 붙어 있는 입력 칸 모음.
3. **사업자등록일**을 고릅니다.
4. **"조회"** 를 누릅니다.
   - 업종이나 사업자등록일 칸을 비운 채 누르면 "업종과 사업자등록일을 입력해 주세요" 안내 문구가 보입니다.
   - 항목 자료에 없는 업종이면 "비슷한 업종: {제안 업종} — 이 업종으로 볼까요?" 질문이 뜹니다. **"네"** 를 누르면 그 업종의 항목 목록이 보이고, **"아니요"** 를 누르면 "'{입력한 업종}' 업종의 세무·행정 항목 자료가 아직 없어요." 안내 문구가 보입니다.
5. 「세무·행정 항목 목록」에서 끝낸 항목의 **체크 칸**을 누릅니다. 「남은 항목 확인」에는 체크하지 않은 항목만 남아서 보입니다.
6. **"목록으로 돌아가기"** 를 누르면 세무·행정 항목 목록으로 돌아갑니다.
7. **"처음으로 돌아가기"** 를 누르면 사업자등록 정보 입력으로 돌아가 다른 업종이나 등록일로 다시 조회할 수 있습니다.
