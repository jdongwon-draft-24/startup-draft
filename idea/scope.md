# 만들 범위

## 떠오른 기능

1. 사업자등록 정보(업종, 등록일)를 입력하면 → 그 업종에 맞는 세무·행정 항목 목록이 자동으로 뜬다(핵심)
2. 부가세 신고 등 마감일이 다가오면 → 달력에 체크리스트로 표시된다
3. 항목을 하나씩 완료 체크하면 → 아직 안 한 항목만 남아서 한눈에 보인다
4. 체크리스트의 각 항목을 클릭하면 → 무엇을, 왜 해야 하는지 쉬운 설명이 나온다
5. 사업자등록 직후 첫 1년 동안 해야 할 절차를 순서대로 정리해 보여주면 → 지금부터 무엇을 언제 해야 하는지 전체 흐름을 알 수 있다
6. 신규 창업자가 자주 놓치는 절차를 모아서 보여주면 → 선배나 세무사에게 물어보지 않아도 스스로 챙길 수 있다

## 한 번 써 보는 순서

1. 업종(IT 서비스 개발업)과 사업자등록일을 입력창에 넣고 "조회" 버튼을 누르면 → 그 업종에 맞는 세무·행정 항목 목록이 뜬다
2. 목록에 뜬 항목 하나를 눌러 마감일이 언제인지 보려고 하면 → 아무 것도 나오지 않는다(막힘)
3. 이미 처리한 항목(예: 사업자등록증 수령)을 체크하면 → 체크 표시가 된다
4. 체크한 항목이 목록에서 빠지고 → 아직 안 한 항목만 남아서 한눈에 보인다
