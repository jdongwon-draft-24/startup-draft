# 내 아이디어 후보

## 후보 1 - 사업자등록 정보를 넣으면, 부가세 신고 같은 세무·행정 마감일이 달력에 체크리스트로 뜨는 서비스

- 무엇을 만드나 : [사업자등록 정보를 넣으면, 부가세 신고 같은 세무·행정 마감일이 달력에 체크리스트로 뜨는 서비스]
- 누가 겪는 문제인가 : [사업자, 특히 소규모 사업장처럼 체계화되지 않은 기업체]
- 팀이 준 말 : [사업자라면 필요하겠다고 함]
- 만들 수 있나 : [문자나 알림 서비스는 구현이 어려울 듯 하다고 함]
- 쓸 사람 (1인 페르소나) :
  - 누구인가 : 사업자등록한 지 1개월 된, IT 서비스 개발업 1인 창업자
  - 언제 : 사업자등록을 막 마친 직후
  - 왜 : 사업 경험이 없어서 어떤 세무·행정 절차를 해야 하는지 자체를 모름
  - 지금은 어떻게 : 주위 창업한 선배들에게 물어보거나 세무사 등에게 문의함

## 후보 2 - 나이·소득·사는 곳 같은 조건을 화면에 입력하면, 받을 수 있는 지원금 목록이 바로 보여주는 서비스

- 무엇을 만드나 : [나이·소득·사는 곳 같은 조건을 화면에 입력하면, 받을 수 있는 지원금 목록이 바로 보여주는 서비스]
- 누가 겪는 문제인가 : [사업자, 개인 등]
- 팀이 준 말 : [누구나 혜택을 원해서 좋아할 듯 하다고 함]
- 만들 수 있나 : [자동 알림 기능은 빼야 한다고 함]

## 후보 3 - 내가 여행한 도시를 세계지도에 표시하는 화면

- 무엇을 만드나 : [내가 여행한 도시를 세계지도에 표시해 주는 화면]
- 누가 겪는 문제인가 : [여행을 좋아하는 사람]
- 팀이 준 말 : [주위에서는 좋다고 함]
- 만들 수 있나 : [가능할 듯 함]
- 쓸 사람 (1인 페르소나) :
  - 누구인가 : 여행을 좋아해서 1년에 2회 이상 해외여행을 가는 사람
  - 언제 : 새로운 나라/도시를 다녀왔을 때마다
  - 왜 : 매번 기록하기 불편함
  - 지금은 어떻게 : 메모앱에 적는다

## 아직 못 버린 것

- [전월세 계약서 파일을 올리면, 세입자에게 불리한 조항에 표시를 해서 보여주고, 위험한 조항을 찾아주는 데서 더 나아가, 그 조항을 어떻게 고치면 좋을지 대체 문장까지 같이 제안해 주는 서비스] - [불리한 조항에 표시를 해서 보여주고"가 원본 파일 안에 색칠해서 보여주는 것까지라면 어려울 수 있다고 함]
